# Git 工作台侧边聊天：实现与验证记录

验证日期：2026-09-29。运行环境：DSH 0.2.0-rc.1、真实 Git 仓库、本地裸远程仓库。
官方源码对照：deepseek-ai/deepseek-harness，commit `4878cdabd87d4041bdaff61d04c966883b9fd07a`。

## 实现范围

- 建议页上方复用 DSH 原生 Conversation、SessionProvider、附件上传和模型/推理等级控件；下方保留结构化建议和执行按钮。公共命令日志仍位于工作台底部。
- 通过原生会话 fork 创建独立侧会话；主会话 ID 与侧会话 ID 的对应关系保存在 DSH JSON storage 的 `easygit_chats`。聊天历史由 DSH 保存。
- 创建时继承主会话当前模型及推理等级，此后双方独立。主会话内容增量单向同步，后台同步不唤醒模型；每次侧边推理前补齐取消、断线或恢复期间的上下文。
- Git 失败分析请求和执行结果发送到侧会话；建议仍通过 `git_propose` 生成，保存在对应主会话的建议列表。
- 按方案 A，侧边模型可读取文件、图片和仓库状态。写操作、Shell 和委派执行由工具 guard 拦截；修改必须由用户点击建议执行按钮，高风险建议保留风险确认。
- 建议执行与工作台写操作共用仓库锁。执行前比较分支、引用、索引、工作区内容、未跟踪文件和仓库本地配置的快照；过期建议失效并反馈给助手重新分析。自动修正建议继承会话归属与新快照；重复执行不会重复唤醒模型。
