## 本轮发现并修复

1. **提交详情的中文文件名显示为 Git 八进制转义。** 浏览器复现后，将文件摘要改为 `--name-status -z` / `--numstat -z`，正确解析普通及重命名记录。新增真实 Git 回归涵盖根提交、中文、引号、制表符、换行、重命名和二进制统计；旧实现失败，修复后通过。浏览器再次显示 `中文 空格.txt` 正常。
2. **模型工具漏传会话沙箱策略，误报真实目录不是仓库。** 真实侧边模型能够同步主会话代号，但 `git_repo_state` 错误返回非仓库。修复仓库读取、建议登记、仓库锁定位、执行诊断、复制后验证和失败恢复的策略传递。侧边读取与建议使用对应主会话的目录和策略。回归测试逐次断言 Shell 请求携带策略；重启 DSH 后真实模型成功读取仓库、登记建议，点击执行后实际创建分支，结果只反馈给侧边会话。
3. **读取失败的空输出可能被当作验证成功。** 分支删除、贮藏清空等状态验证现在同时要求 Git 返回成功退出码。新增失败读取回归，确保不会把 `exitCode=128` 的空输出判断为目标已达成。
